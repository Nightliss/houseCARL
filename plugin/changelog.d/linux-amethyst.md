- **houseCARL now runs on Linux and reads an Amethyst Mod Manager profile, alongside MO2.** Point `housecarl_set_mo2_instance` (or the `amethyst_instance_dir` setting) at the game's Amethyst folder holding `profiles/`; houseCARL follows the profile Amethyst has active, like MO2's selected profile. A profile folder, or the folder with `profile=`, pins one profile; new plugins land in its overwrite folder, and messages say Amethyst instead of MO2. `scripts/build-plugin.sh` builds the plugin.
